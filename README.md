# 资料分析真题化训练 · 行测考点全覆盖练习工具

一个开箱即用的公考行测「资料分析」刷题网页工具：覆盖全部 25 个资料分析考点、79 道真题化题目（历年真题 23 题 + 真题化训练 56 题），支持**随机分组练习**、计时判分、逐题解析、错题本与练习统计。纯静态单文件，可离线使用，可直接部署到 GitHub Pages。

## 功能特性

- **考点全覆盖**：现期量 / 基期量 / 增长量 / 增长率 / 百分点 / 隔年增长率 / 年均增长率 / 年均增长量 / 混合增长率 / 拉动增长与贡献率 / 现期·基期·两期比重 / 比重变化判断 / 现期·基期平均数 / 平均数增长率与增长量 / 现期·基期倍数 / 基期量和差 / 和差计算 / 读数与排序比较，共 25 个考点。
- **真题化题库**：收录历年真题（2023 国考行政执法类 4 篇、2018 国考副省级、2018 联考等），并以真题素材改编、真题化设计补齐其余考点；每道题标注来源（真题 / 真题改编 / 真题化训练）。16 组材料覆盖表格、图表与文字材料三种题型。
- **随机分组练习**：可选来源范围、每组题量（5/10/15/20/全部）、按考点筛选；每次「开始」随机抽题、材料自动配组。
- **资深命题人视角**：每道题解析包含「干扰项设计」——逐一拆解每个错误选项对应的典型误区，并内置命题人干扰项设计六大规律（时间、单位、概念偷换、比重方向、间隔漏项、估算陷阱）。
- **完整闭环**：计时答题 → 一键交卷判分 → 成绩环与考点统计 → 逐题解析；错题自动入错题本，可单题重练或整体重练。
- **本地统计**：练习历史、各考点正确率、错题本均保存在浏览器 localStorage，不上传任何服务器；支持导出 JSON 成绩。

## 本地使用

直接用浏览器打开 `资料分析真题练习.html` 即可（双击或拖入浏览器），无需安装任何环境。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库（如 `ziliao-fenxi-practice`），**不要勾选**「Add a README」以免冲突。
2. 将 `资料分析真题练习.html` 改名为 `index.html` 后上传到仓库根目录（也可保留原名，但 Pages 默认读取 `index.html`）。
3. 仓库页面进入 **Settings → Pages**：Source 选择 `Deploy from a branch`，Branch 选择 `main` / `master`，目录选 `/ (root)`，保存。
4. 等待 1–2 分钟，即可通过 `https://<你的用户名>.github.io/<仓库名>/` 访问，手机电脑均可使用。
